# AI购物 pilot 小结

## 我们在做什么
- 我们在跑一个 pilot：每天定时用 OpenAI API 问 ChatGPT 所用的模型「该买哪个洗发水、洗衣液」，记录它推荐哪些品牌，用来判断正式采集该怎么设计。
  - We are running a pilot: on a daily schedule, we ask the model behind ChatGPT, via the OpenAI API, which shampoo or laundry detergent to buy, and record which brands it recommends. The aim is to decide how the main data collection should be designed.
- 研究目的：关注消费者用 AI 搜索产品时，模型推荐哪些品牌。
  - Research aim: which brands the model recommends when consumers use AI to search for products.

## Pilot 要回答的问题
- 1）API 已经带了地点参数（user_location），提问文字里再写「我在某国」，结果有没有区别。
  - 1) Given that the API already sends a location parameter (user_location), does stating "I'm in [country]" in the question text change the result?
- 2）换一种问法，结果会不会有很大区别。
  - 2) Does a different wording of the question change the result substantially?
- 3）一天里不同时段问，结果有没有区别。
  - 3) Does the time of day at which we ask make a difference?
- 4）费用估计。
  - 4) Cost estimate.

## 采集设计
| 维度 Dimension | 取值 Values | 数量 n |
|---|---|---|
| 产品 Product | 去屑洗发水、去渍洗衣液 (anti-dandruff shampoo, stain-removing detergent) | 2 |
| 问法 Wording | which … should I get / what's a good … / can you recommend … | 3 |
| 文字里的地址 Country in text | 写 ("I'm in the UK, …") / 不写 (stated / not stated) | 2 |
| 时段 Time slot | 当地 9 至 11 点、15 至 17 点、20 至 22 点 (local) | 3 |
| 市场 Market | 英国、美国、德国、法国，各用当地语言提问 (UK, US, DE, FR, local language) | 4 |

- 每个市场每个时段 2 × 3 × 2 = 12 条，每天共 144 条。
  - 2 × 3 × 2 = 12 replies per market per slot, 144 per day in total.
- 模型：`chat-latest`，OpenAI 官方别名，指向 ChatGPT 当前使用的 Instant 模型。它不返回版本号，模型更新只能间接发现（目前每天的回答长度和 token 用量都很稳定）。
  - Model: `chat-latest`, OpenAI's official alias for the Instant model currently used in ChatGPT. It returns no version number, so model updates can only be detected indirectly (so far answer length and token use are stable day to day).
- 联网搜索：强制开启，每条都会搜索；地点参数：API 里始终带国家和时区。
  - Web search is forced on, so every reply searches; the API always sends the country and time zone as the user's location.
- 无状态：每条都是独立调用（`store=False`），不存储、无记忆或上下文。但 API 输出和 ChatGPT 应用里看到的不完全相同（系统提示、购物卡片等界面元素 API 不返回）。
  - Stateless: each call is independent (`store=False`), with no storage, memory or context. API output is not identical to what the ChatGPT app shows (system prompt, shopping cards and other UI elements are not returned by the API).
- 记录内容：完整原始响应、搜索来源、返回的模型名、token 用量、当地采集时间、是否准点。
  - Logged: full raw response, search sources, returned model name, token usage, local collection time, and whether the slot was on time.
- 触发：cron-job.org 每个整点调用 GitHub Actions。GitHub Actions 的时间额度在正式采集前需要处理（私有仓库每月 2000 分钟免费额度，每小时触发会接近上限）。
  - Trigger: cron-job.org calls GitHub Actions every hour. The Actions minutes quota needs handling before the main study (private repos get 2,000 free minutes a month; hourly triggering gets close to that limit).
- 实际数据：2026-11-13 至 11-17，共 657 条有效回复（11-17 晚上 API 余额用完，最后几个时段不完整）。
  - Data collected: 2026-11-13 to 11-17, 657 valid replies (API credit ran out on the evening of 11-17, so the last few slots are incomplete).

## 目前的发现
分析 notebook：[pilot_analysis.ipynb](https://github.com/joanne-ren/ai-shopping-pilot/blob/main/analysis/pilot_analysis.ipynb)

- 推荐高度集中，品牌池很小：每个市场 × 产品约 80 条回复，不同品牌只有 5 至 12 个；每条回复平均提到 2 至 3 个品牌。
  - Recommendations are highly concentrated and the brand pool is small: about 80 replies per market × product name only 5 to 12 distinct brands, and each reply names 2 to 3 brands on average.
- 每个市场都有 1 至 3 个「必出现」的头部品牌，出现率接近 100%：英国 Nizoral、Ariel、Persil；美国 Tide、Head & Shoulders、Selsun、Nizoral；德国 Ketozolin、dm 自有品牌（Denkmit）；法国 Ducray、Ariel。
  - Each market has 1 to 3 "always there" lead brands with a mention rate near 100%: UK Nizoral, Ariel, Persil; US Tide, Head & Shoulders, Selsun, Nizoral; Germany Ketozolin, dm's own label (Denkmit); France Ducray, Ariel.
- 问题里写国家：德国、法国变化大，英美基本不变。例如法国洗衣液 Persil 出现率 73% 降到 19%，Skip 20% 升到 60%。
  - Stating the country in the question: large shifts in Germany and France, little change in the UK and US. For example, in French detergent Persil falls from 73% to 19% and Skip rises from 20% to 60%.
- 问法：影响和「写国家」差不多大，集中在中间层品牌；头部品牌不受影响。例如法国洗发水 Vichy 在三种问法下为 75 / 61 / 21%。
  - Wording: an effect about as large as stating the country, concentrated on mid-tier brands; lead brands are unaffected. For example, Vichy in French shampoo is at 75 / 61 / 21% across the three wordings.
- 时段：看不出影响，每天 3 个时段可以当作 3 次重复。
  - Time of day: no visible effect, so the three daily slots can be treated as repeats.
- 费用：每条约 $0.06，48 条/天约每月 $88、半年约 $535。
  - Cost: about $0.06 per reply; 48 replies a day comes to about $88 a month and $535 for six months.
